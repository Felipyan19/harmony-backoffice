# Harmony Backoffice

Backoffice operativo de Harmony Spa para gestionar clientes, conversaciones y atención humana.

## V1

- Inbox de conversaciones
- Gestión de clientes
- Mensajería operativa
- Base preparada para integrar WhatsApp/agent backend

## Stack

- Next.js App Router
- TypeScript
- React
- CSS Modules / global design tokens
